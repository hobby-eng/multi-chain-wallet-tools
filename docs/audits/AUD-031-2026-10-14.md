#### AUD-031-API001 — medium — Worker replies lose stable refusal code and native error kind

- **status:** fixed
- **reproduction:** Send a synthetic coded RangeError reply through MnemoCodeWorker. The before-fix test expected RangeError and failed because the client reconstructed plain Error without code.
- **expected:** Keep the immutable module code, safe refusal message and native Error/TypeError/RangeError kind; never serialize arbitrary cause or private buffers.
- **observed:** The worker sent only message and the client created new Error(message). Unknown thrown values were stringified.
- **impact:** Hosts cannot reliably distinguish a module refusal from another failure; stringifying an unknown fault may repeat supplied text. No real secret disclosure or browser exploit was demonstrated.
- **recommendedFix:** Use the shared MnemoCodeWorkerProtocol for deliberate error-field transport and native reconstruction, with generic safe text for uncoded operational faults.
- **requiredVerification:** Coded kind/code/message controls, immutable code, cause exclusion and unknown-fault privacy fixtures; real-browser acceptance remains unexecuted.
- **Evidence:** local AUD-031-evidence/worker-code-before.command.json; local AUD-031-evidence/targeted-final.command.json.

#### AUD-031-API002 — medium — Host search adapters still treat library cancellation as an error or completed result

- **status:** fixed
- **reproduction:** Abort a word/date wallet callback or deliver a library stopped reply. The old host imported assertStillRunning, ignored returned stopped state and used error text to identify cancellation; this is incompatible with the frozen library contract.
- **expected:** A stop remains distinct from no-match, a question, a complete candidate list and an operational failure. Suppress and wipe candidate bytes completed after the stop.
- **observed:** Adapters retained throw-based checks and built completed search/list presentation from partial library results. Worker termination rejected with a message which the page parsed.
- **impact:** Interrupted work can be misclassified and incomplete results can look final. Evidence is source-contract analysis plus bounded public-fixture controls; it does not demonstrate loss of funds.
- **recommendedFix:** Return stopped results, reuse one publication/wipe owner, discard them in the shared job boundary, and leave stopped Re-encode wallet comparisons unconfirmed.
- **requiredVerification:** Pre-aborted and callback-stopped searches, late candidate-byte wipe, stopped job versus operational fault, Re-encode confirmation and share-controller regressions.
- **Evidence:** local AUD-031-evidence/targeted-final.command.json; local AUD-031-evidence/final-fast-gates.command.json.
