# AUD-023 remediation harnesses

These scripts belong to reviewer "remediation" of AUD-023. They re-run the reproductions of thirteen AUD-022 findings (API001 to API007, FUN001, FUN002, SEC001, SEC002, UI001, UI002) against the fixes in the working tree, and try nearby orderings and inputs that the AUD-022 "required verification" names. Reviewed source: HEAD `c5b62c2d489e7525326071128095ba95ecca92ac` plus the uncommitted tree recorded in `docs/audits/AUD-023-evidence/snapshot-baseline.json` (fingerprint `8e8649c9059d2bdeb84d5eccb2d1191142888c0c32601df1276116d640b873aa`, 1091 paths). Most files are adapted copies of `docs/audits/AUD-022-harnesses/`; the AUD-022 files themselves are unchanged.

Inputs are public data only: the BIP39 all-zero phrase (`abandon … about`), the BIP39 test passphrase `TREZOR`, MnemoCode's public SSKR vector `bip39-128-2-of-3`, synthetic list passphrases, synthetic PSBTs with zero outpoints and no signatures, and synthetic client replies. Nothing runs Argon2, a Docker build or a full test suite. Run everything from the repository root with Node 26.10.0 and the installed pnpm dependencies. Record a run with `node docs/audits/AUD-023-harnesses/record-command.mjs <unique-name> -- <command>`; logs stay in the ignored `docs/audits/AUD-023-evidence/`.

## VM probes of the page classes (light)

`remediation-vm-support.mjs` evaluates unchanged production TypeScript in `node:vm` modules with a small DOM stub. Before evaluating a file it compares the file's SHA-256 with `snapshot-baseline.json`; drift is a harness error (exit 2). Changes from the AUD-022 support file: the new binding; events bubble through `parentNode` as `input` and `change` do in a browser, because the fixed Check tab listens on its panel; `input[name="x"]:checked` is understood; a replacement can load a real file (`realFile`), which is hash-checked too. Each probe prints one JSON line per case with boolean checks, then a summary with the loaded file hashes. Exit 0: every check held; 1: a check failed; 2: harness or binding error. Node prints an experimental-VM warning.

`REMEDIATION_MUTATION='{"file":"<repository path>","from":"<text>","to":"<text>"}'` rewrites that text in memory after the hash check (the file on disk is not touched), so that a run can show that the probe fails when the fix is taken out; the summary names the mutation. Pass it through `env` when recording.

## Browser probe (heavy: starts browsers)

`remediation-browser-share-list.mjs` uses the coordinator's fresh `dist/` (read only) of both editions in pinned Chromium and Firefox. Per edition it shows the Scanner's one-time key, restores the vector shares in the Deriver's MnemoCode › Restore with a list to that key and the BIP39 passphrase `TREZOR`, saves the file (downloads go to `docs/audits/AUD-023-evidence/scratch/remediation/` and are deleted), opens it in the Scanner (expects "1 candidate from the list, with the BIP39 passphrase stored in the list"), removes it, then in the Deriver's Forgotten tab runs a word search that no word completes with a list asked for (expects "No candidate to save, so no list was written." and no Save button) and a 257-byte stored passphrase (expects the refusal before any search). Every HTTP(S) request is aborted and must not occur; page errors must not occur. It prints a JSON report with the artifact SHA-256 values.

```sh
flock docs/audits/AUD-023-evidence/heavy.lock node docs/audits/AUD-023-harnesses/remediation-browser-share-list.mjs
```

`BROWSER_ENGINES` (default `chromium,firefox`) and `BROWSER_PROFILE` (`multi-chain` or `dash-community`) narrow the run. Exit 0: all four runs pass; 1: a check failed; 2: a browser could not start. Expected on the baseline build: four passing runs with six checks each.

## Unchanged AUD-022 harnesses on the current tree

The non-snapshot-bound AUD-022 Vitest probes were also run unchanged. The MnemoCode and crypto probes pass. The scanner probes and `mhfe-contract-probes.mjs` fail for harness reasons that the adapted copies above remove: the panel probe waits for an `onChange` that the fixed panel no longer emits for a dropped open; the importer probe passes a `Uint8Array` where `open()` takes a file; the MHFE probe predates `PasswordReview.choose(run, …)` and the engine's `runtime.js` import. The AUD-022 `deriver-*.mjs` probes are bound to the AUD-022 snapshot and are not rerun; their adapted copies are listed above.
