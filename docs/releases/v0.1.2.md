# Multi-Chain Wallet Tools v0.1.2

This release expands Dash Identity support, adds mixed batch queries and structured spreadsheet exports to the Activity Viewer, and hardens the reproducible build and security boundaries across all three standalone tools.

## New capabilities

- Added Dash DIP13 Identity derivation with the standard four-key registration profile.
- Added proof-verified Dash Platform Identity state and registered-key lookup to the Activity Viewer.
- Added Identity lookup by Base58 ID, explicit hexadecimal ID, registration transaction, key fingerprint, public key, and DPNS name.
- Added local validation of Identity creation transactions before resolving their owners through proof-verified DAPI.
- Added Identity result categories for overview, names, keys, activity, documents, contracts, withdrawals, and tokens.
- Added readable Identity ledger events that deduplicate owner transactions and transfer legs sharing one transaction hash.
- Made Single and Batch the primary Activity Viewer query modes.
- Added local Auto input detection while retaining Advanced explicit type selection.
- Added mixed Core, Platform address, Platform Identity, and Orchard batch queries with bounded concurrency and independent per-input errors.
- Reused each proof-verified Orchard page across every viewing key in the same batch instead of repeating the network traversal.
- Redesigned CSV export as compact relational rows without repeating complete account summaries on every record.
- Redesigned JSON export as complete object-oriented records grouped by queried resource.
- Added local XLSX export with separate Summary, Addresses, Identities, Orchard, and Errors worksheets.
- Preserved exact large integer values in every export and prevented spreadsheet formula execution.
- Excluded Orchard viewing keys from every export path, including failed batch records.
- Refreshed Activity Viewer headings, controls, diagnostics, result layout, privacy copy, and the release passport for all four resource types.

## Reproducible builds and maintenance

- Added the canonical Ubuntu 24.04 Docker build used for official release artifacts.
- Pinned the Docker base image, Node.js, pnpm, Rust/Cargo, wasm-bindgen, GitHub Actions, and Dash JavaScript dependencies.
- Made the final verification and artifact-build layer run without network access.
- Added deterministic double-build comparison and clearer separation between source fingerprints and downloadable-file checksums.
- Added a shared Dash SDK build check and shared strict HTTP/response parsing for network providers.
- Enabled unused TypeScript declaration and parameter checks.
- Split each application's large UI entry point into a thin composition root, controller, and view layer.
- Added weekly Dependabot coverage and a separate upstream-version review workflow that never modifies release inputs automatically.
- Added only the two compact XLSX runtime dependencies, `write-excel-file` and `fflate`, with pinned versions and documented licenses.

## Security and verification

- Added an immutable encrypted Orchard action fixture produced by the official stable Dash Platform wallet implementation.
- Expanded FVK, IVK, and OVK recovery tests, malformed-input checks, spent reconstruction, and scanner-boundary coverage.
- Hardened controller cancellation, stale-result prevention, secret cleanup, and artifact boundaries.
- Expanded private-material detection for Activity Viewer single and batch inputs before any network request.
- Strengthened static verification that the connected Evo SDK facade is used only through approved read/proof operations.
- Added stricter CSP, embedded-script, dependency-version, generated-WASM, and private-build-path artifact checks.
- Documented indexed-provider trust, proof precedence, export privacy, WASM panic cleanup limitations, and cross-browser release checks.

The release remains read-only. The Activity Viewer and Discovery Scanner do not construct, sign, prove, or broadcast transactions. Always verify funded resources and derivation paths in a standard wallet before recovery. This hobby project has not received an independent cryptographic security audit.
