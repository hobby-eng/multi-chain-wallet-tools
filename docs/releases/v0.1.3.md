# Multi-Chain Wallet Tools v0.1.3

This release expands the universal Multi-Chain Edition with Bitcoin and Ethereum discovery and activity lookup while keeping Dash Community Edition focused entirely on Dash. Both editions are built from the same reviewed source and carry version 0.1.3.

## Multi-chain discovery

- Added Bitcoin seed recovery for Legacy, Nested SegWit, Native SegWit, and Taproot receive/change accounts, with an independent 20-address post-use gap for each family and branch.
- Added Ethereum seed recovery for Standard BIP44/MetaMask/Trezor, Ledger Live, and Legacy Ledger/MEW account layouts.
- Added separate Seed phrase and Public keys tabs, each with Single and Batch modes.
- Added public-key discovery for supported SEC1 keys, account and branch xpub/tpub keys, SLIP-132 Bitcoin keys, checksummed Bitcoin descriptors, Dash Core and Platform keys, Dash Identity keys, and Dash Orchard viewing keys.
- Added an explicit coin selector. Unambiguous formats select their coin locally; shared formats require the user to choose a coin before scanning.
- Added optional custom derivation paths for coin adapters that support them.
- Added previously used zero-balance address discovery alongside the default funded-only view.

## Address activity and history

- Added Bitcoin and Ethereum public-address lookup to the Multi-Chain Activity Viewer, with Bitcoin selected by default.
- Added Single and Batch address lookup with current balance, confirmed lifetime received and sent totals, transaction counts, and First seen/Last seen dates when complete provider data is available.
- Added the same history fields to Discovery Scanner findings for Bitcoin, Ethereum, and Dash where supported.
- Kept incomplete or unavailable history explicit instead of presenting partial data as complete lifetime totals.
- Added bounded pagination, provider fallbacks, cancellation, and duplicate-address suppression for connected Bitcoin and Ethereum scans.

## Dash recovery coverage

- Added optional Dash legacy mobile Core, Dash Mobile CoinJoin · DIP9, identity-funding, and provider-holdings derivation families.
- Clarified that Dash Core desktop CoinJoin outputs use the ordinary BIP44 receive/change scan, while the separate DIP9 family covers mobile CoinJoin compatibility.
- Added Dash watch-only discovery for Core, Platform payment, Identity, and Orchard public material.
- Linked discovered Dash Platform identities to their actual L1 asset-lock funding transactions where the required public data is available.
- Preserved separate accounting for Dash Core duffs and Dash Platform credits and reviewed all three utilities for unit consistency.

## Editions and presentation

- Restored Bitcoin, Ethereum, and Dash selection throughout the universal Multi-Chain Edition while keeping Dash Community Edition compiled and presented as Dash-only.
- Kept Bitcoin as the default coin wherever it is available.
- Simplified network selectors to Mainnet and Testnet when the coin is selected separately.
- Updated Dash Community styling to follow the official Dash BrandBook and Brand Guidelines.
- Moved build outputs into symmetric `dist/multi-chain-edition/` and `dist/dash-community-edition/` directories.
- Updated the repository README to describe the current capabilities and the distinction between both editions.

## Security, exports, and verification

- Kept seed derivation inside the sandboxed, network-denied Secret Vault and public lookups inside the separate network worker.
- Kept extended public keys and Orchard viewing keys local and excluded them from recovery exports.
- Added coin-independent history fields and exact atomic-unit values to CSV and JSON recovery reports.
- Expanded deterministic and live smoke coverage for multi-chain, public-key, history, batch, profile-isolation, and release-asset workflows.
- Updated all workspace and application versions to 0.1.3.

The release remains read-only. The Activity Viewer and Discovery Scanner do not create, sign, or broadcast transactions. Verify every funded address and derivation path in a standard wallet before recovery. This independent hobby project has not received an external cryptographic security audit.
