# Dash Community Wallet Tools v0.1.4

**Released 2026-09-13.** This Dash-only edition is compiled from the canonical [Multi-Chain Wallet Tools v0.1.4 source tag](https://github.com/hobby-eng/multi-chain-wallet-tools/tree/v0.1.4). It contains only Dash Core, Platform Payments, Identity, Orchard, and the supported Dash PSBT/Script workflows.

## Highlights

- Added the offline **Dash Community PSBT & Multisig Inspector** for supported Dash PSBT v0 and Script review, public-message verification, BIP38 decryption, and test P2SH multisig/watch-only policy construction. It does not sign, finalize, fund, query UTXOs, or broadcast transactions.
- Added optional local Dash message signing and compatible compressed-P2PKH BIP38 encryption to Deriver without importing a key into Dash Core.
- Added Dash Core public/private account descriptor exports for BIP44, legacy mobile, and Mobile CoinJoin receive/change branches. Public descriptors are watch-only; private descriptors grant account spending access.
- Added Purpose48 P2SH multisig cosigner derivation, with an explicit warning that the legacy script-type convention is wallet-specific.
- Added automatic checking of prepared BIP39 candidates, editable custom paths/account ranges, and labelled legacy-mobile public scan keys.
- Added complete Platform Payment receive/internal scanning and strengthened Core, Platform Identity, and Orchard discovery/history handling.
- Updated the Dash Community interface using the official Dash BrandBook and Brand Guidelines while retaining the shared accessibility and security behavior.

## Correctness and verification

- Fixed Orchard reconciliation while the pool changes, action counts for empty aligned pages, and balance claims for incomplete scans.
- Removed cross-run result caches and strengthened checksum, amount, response-size, pagination, cancellation, Identity-history, descriptor, Script, PSBT, and worker-readiness validation.
- Added official and differential derivation regressions, Chromium/Firefox direct-`file://` acceptance, extended browser regressions, and a machine-readable verification record.
- Updated Vitest to 5.0.0 and wasm-bindgen runtime/CLI to 0.2.128.
- All files in this release were produced by the Dash distribution workflow from the immutable canonical source tag. Their provenance attestations are recorded against `hobby-eng/dash-wallet-tools`; `SHA256SUMS` and the included `verification-record.json` cover the Dash Community files.

Verify an HTML file online with GitHub CLI, using the Dash release repository that issued the attestation:

```bash
gh attestation verify Dash_Community_Key_Derivation_Tool.html -R hobby-eng/dash-wallet-tools
gh attestation verify Dash_Community_Activity_Viewer.html -R hobby-eng/dash-wallet-tools
gh attestation verify Dash_Community_Discovery_Scanner.html -R hobby-eng/dash-wallet-tools
gh attestation verify Dash_Community_PSBT_Multisig_Inspector.html -R hobby-eng/dash-wallet-tools
```

For offline integrity checking, download all release files into one directory and run `sha256sum -c SHA256SUMS`.

## Safety notes

Use the Deriver and Inspector offline for sensitive material. Public lookups reveal queried identifiers and source IP addresses to providers. Orchard viewing keys cannot spend funds but reveal wallet activity. The Scanner cannot cross hardened derivation levels from a public key. Restore and move valuable funds with a maintained Dash wallet after independently confirming all results.
