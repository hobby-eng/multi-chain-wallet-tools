# Multi-Chain Wallet Tools v0.1.1

This release focuses on making Dash wallet discovery scans faster to configure and substantially more useful for recovery and historical analysis.

## Improvements

- Added independent scan switches for Dash Core L1, Platform payment addresses, Platform identities, and the Orchard shielded pool.
- Hidden range and gap controls for disabled components so the form shows only relevant settings.
- Added complete Dash Core address history fields: transaction count, lifetime received/sent totals, and first/last-seen timestamps.
- Added a verified fallback for special Core transactions whose DashScan address summary omits the first-seen timestamp.
- Added Platform payment-address and Identity history: operation counts, incoming/outgoing credit events, lifetime received/sent totals, Identity fees, and first/last-seen timestamps.
- Kept Platform balances authoritative through DAPI proofs; auxiliary Platform Explorer history is accepted only after synchronization, network, resource, and exact balance checks.
- Added Orchard note-level statistics: received, sent, self/change, spendable and spent note counts; lifetime amounts; memo counts; note values; and first, last, and spend pool positions.
- Added component-aware CSV exports. Core-only reports no longer contain empty Platform, Identity, or Orchard columns; mixed scans contain only the union required by selected components.
- Added all new public historical fields to JSON and numeric spreadsheet-friendly CSV columns.
- Updated security documentation and artifact checks for the expanded fixed Network Worker protocol.

## Safety and verification

- Mnemonics, passphrases, seeds, derived keys, and Orchard viewing material remain inside the network-denied Secret Vault.
- Only validated public lookup values cross into the isolated Network Worker.
- The release fails closed if cryptographic startup vectors, TypeScript/tests, Rust/WASM verification, CSP/isolation checks, artifact checks, or reproducible double builds fail.
- The Discovery Scanner remains scan-only and does not construct, sign, or broadcast transactions.

Always verify funded resources and derivation paths in a standard wallet before recovery. This hobby project has not received an independent cryptographic security audit.
