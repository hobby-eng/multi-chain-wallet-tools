# Multi-Chain Wallet Tools v0.1.4

**Unreleased working draft.** No publication date has been confirmed. The date in build metadata identifies this preparation snapshot and must be reviewed before publication. Both editions carry version 0.1.4.

## Implemented changes

- Added the experimental offline PSBT & Multisig Inspector in both editions, with Bitcoin/Dash transaction/script inspection, policy and ranged-wallet construction, public message verification and BIP38 decryption. Descriptor and PSBT edge cases remain under review; this is not release acceptance.
- Added local Bitcoin/Dash message signing and optional compatible P2PKH BIP38 encryption to Deriver. Multi-Chain also adds BIP85 child-secret/wallet and BIP352 Silent Payment address derivation.
- Added Dash Purpose48 P2SH multisig cosigner key derivation; wallet compatibility must be checked explicitly.

- Added checksummed Dash Core public-descriptor input in Scanner, with explicit receive/change coverage and coin selection for ambiguous P2PKH descriptors.

- Added public/private account descriptor exports for Bitcoin Legacy, Nested SegWit, Native SegWit and Taproot, plus Dash Core BIP44, legacy mobile and mobile CoinJoin. The Account export dialog provides ready-to-paste Core import commands and raw descriptors for both receive/change branches, including the selected non-default account. Public export does not require revealing private keys; private export does. Added guidance about wallet compatibility when changing the default scheme or account.

- Added automatic checking of ready seed candidates across selected coins, with sequential scanning and a shared outcome summary. Invalid candidates and failed coin checks no longer prevent the remaining automatic checks; available address details and public reports remain accessible.

- Added a visual standard-path breakdown to the Key Derivation Tool. Purpose, coin type and address scheme remain fixed by the selected protocol; only its supported account, branch and index controls are editable.

- Added a visual custom-path editor and optional account range with prefilled, fully editable Start/Finish paths. Custom accounts use their address minimum plus 20 and extend after activity. Standard scans run once; arbitrary single paths remain supported.

- Added explicitly labelled Dash legacy mobile public-key discovery on mainnet and testnet, with a public scan key export in the Key Derivation Tool. An account key covers its receive and change branches; a branch key covers only that branch.
- Fixed Orchard partial-chunk reconciliation when the pool grows during a scan. Repeatedly changing data produces an incomplete result instead of an authoritative balance.
- Fixed Orchard action counts so that empty aligned pages do not inflate the count.
- Added limits for provider response sizes, numeric values, and auxiliary Identity history requests.
- Accepted both standard hardened origin markers in Bitcoin descriptors while continuing to verify the checksum against the original input.
- Tightened public-key scan range and prefix validation.
- Centralised descriptor/script consensus and policy limits, strengthened PSBT cross-field and preimage checks, and added permanent official/differential derivation regressions.
- Added one shared derivation-Worker readiness contract and browser regressions for immediate Clear, Cancel, and protocol changes during cryptography startup.
- Added mandatory Chromium/Firefox `file://` acceptance to pull-request and release CI.
- Added a machine-readable verification record covering the source revision, pinned toolchain, verification scope, and every HTML/WASM hash; tagged release assets receive GitHub OIDC build-provenance attestations.
- Updated Vitest to 5.0.0 and the Rust/WASM bridge and CLI to wasm-bindgen 0.2.128, with regenerated browser bindings and synchronized build documentation.
