# Multi-Chain Wallet Tools v0.1.4

**Released 2026-09-13.** Both editions carry version 0.1.4. They are built from the same tagged source revision.

## Highlights

- Added the fourth standalone utility, **PSBT & Multisig Inspector**, in both editions. It decodes supported Bitcoin/Dash PSBT and Script data, reviews descriptors and policies, constructs test watch-only multisig material, verifies public message proofs, and decrypts supported BIP38 keys locally. The Inspector remains experimental and does not sign, finalize, fund, query UTXOs, or broadcast transactions.
- Added local Bitcoin/Dash message signing and compatible P2PKH BIP38 encryption to the Deriver. Multi-Chain also adds BIP85 child-secret derivation with an in-memory child-wallet view and BIP352 Silent Payment address derivation.
- Added public and private account descriptor exports for Bitcoin Legacy, Nested SegWit, Native SegWit, and Taproot plus Dash Core BIP44, legacy mobile, and Mobile CoinJoin. Public exports remain available without revealing private values; private descriptors grant account spending access.
- Added Dash Purpose48 P2SH multisig cosigner derivation and supported Dash Core descriptor import in Scanner. Wallet-specific Purpose48 compatibility must still be checked explicitly.
- Added automatic checking of prepared BIP39 seed candidates across selected coins, with sequential scans, explicit incomplete/error outcomes, and a shared result summary.
- Added visual standard-path controls to Deriver and a fully editable custom-path/account-range workflow to Scanner. Non-default accounts and paths stay explicit in results and exports.
- Added labelled Dash legacy mobile public scan keys for mainnet and testnet, including account- and branch-level coverage.

## Correctness and resilience

- Fixed Orchard partial-chunk reconciliation when the pool changes during a scan, excluded empty aligned pages from action counts, and withheld authoritative balances for incomplete scans.
- Added complete receive/internal coverage for Dash Platform Payments and corrected Dash legacy mobile and DIP9 account handling.
- Removed cross-run balance/history caches, bypassed first-party HTTP caches, pinned Ethereum batches to explicit block heights, and tightened provider response, amount, pagination, timeout, and cancellation handling.
- Strengthened public-address checksum validation, extended-key/prefix handling, descriptor checksum/origin parsing, scan bounds, Identity history reconciliation, and export unit separation.
- Centralised descriptor and Script consensus/policy limits and strengthened PSBT cross-field, preimage, MuSig2, Miniscript, Tapscript, and derivation validation with permanent official and differential vectors.
- Added a shared derivation-worker readiness contract, including regression coverage for immediate Clear, Cancel, and protocol changes during cryptography startup.

## Verification and packaging

- Added mandatory Chromium and Firefox direct-`file://` acceptance and extended browser regressions to pull-request and release CI.
- Added a machine-readable `verification-record.json` containing the source revision, pinned toolchain, verification scope, and HTML/WASM hashes.
- Multi-Chain release assets are built from the tag in the pinned canonical container and receive GitHub OIDC build-provenance attestations. The separate Dash Community workflow checks out the same immutable tag, repeats that build, verifies the Dash-only bundle, and issues attestations in its distribution repository.
- Updated Vitest to 5.0.0 and wasm-bindgen runtime/CLI to 0.2.128, with regenerated browser bindings and synchronized Docker/native-build documentation.
- Reorganized documentation into a user-facing README, a conceptual Dash guide, and a detailed implementation/verification reference without discarding the technical record.

## Safety notes

Use the Deriver and Inspector offline for sensitive material. Connected lookups disclose public identifiers and source IP addresses to their providers. Orchard viewing keys cannot spend funds but reveal wallet activity. Public-key discovery covers only paths reachable below the supplied key. None of the four tools creates, signs, or broadcasts recovery transactions; independently verify findings and imports in a maintained standard wallet.
