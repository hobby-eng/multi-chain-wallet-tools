# Multi-Chain Wallet Tools v0.1.4

**Unreleased working draft.** No publication date has been confirmed. The date in build metadata identifies this preparation snapshot and must be reviewed before publication. Both editions carry version 0.1.4.

## Implemented changes

- Added public/private account descriptor exports for Bitcoin Legacy, Nested SegWit, Native SegWit and Taproot, plus Dash Core BIP44, legacy mobile and mobile CoinJoin. Both receive/change branches are exported, with a separate public copy action for Scanner.

- Added automatic checking of ready seed candidates across selected coins, with sequential scanning and a shared outcome summary. Invalid candidates and failed coin checks no longer prevent the remaining automatic checks; available address details and public reports remain accessible.

- Added a visual standard-path breakdown to the Key Derivation Tool. Purpose, coin type and address scheme remain fixed by the selected protocol; only its supported account, branch and index controls are editable.

- Added a visual custom-path editor and optional account range with prefilled, fully editable Start/Finish paths. Custom accounts use their address minimum plus 20 and extend after activity. Standard scans run once; arbitrary single paths remain supported.

- Added explicitly labelled Dash legacy mobile public-key discovery on mainnet and testnet, with a public scan key export in the Key Derivation Tool. An account key covers its receive and change branches; a branch key covers only that branch.
- Fixed Orchard partial-chunk reconciliation when the pool grows during a scan. Repeatedly changing data produces an incomplete result instead of an authoritative balance.
- Fixed Orchard action counts so that empty aligned pages do not inflate the count.
- Added limits for provider response sizes, numeric values, and auxiliary Identity history requests.
- Accepted both standard hardened origin markers in Bitcoin descriptors while continuing to verify the checksum against the original input.
- Tightened public-key scan range and prefix validation.
