Large scans are allowed and the counts above are minimums. Every Core and Platform branch continues until 20 addresses after the last used address, so a minimum of 100 can automatically become 120, 140, or more. For example, 100,000 Core addresses require about 2,000 public DashScan batches per selected branch. Results appear progressively and cancellation is checked between batches; CPU, network traffic, memory used by findings, and total time can still be substantial.

Batch seed scans and every HTTP/DAPI operation use separate bounded concurrency controls; no more than five network operations run at once.

Recommended recovery path

Verify the report, install a standard Dash wallet from its official source on a clean device, restore the same mnemonic and BIP39 passphrase, confirm the listed derivation paths, and move funds to a newly generated wallet. The export intentionally contains no mnemonic, passphrase, seed, private key, spending key, or viewing key.
